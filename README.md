# Educational RAG Platform

## Project Overview
This project is an AI-powered educational assistant designed to help students with O-Level/A-Level subjects (Physics, Chemistry, Computer Science). It utilizes RAG (Retrieval Augmented Generation) to provide answers sourced directly from textbooks.

## Getting Started

### 1. Project Specifications
Please read the [Project Specifications](./PROJECT_SPECIFICATIONS.md) carefully. It contains the architectural details, database schema, and implementation roadmap.

### 2. Prerequisites
- Python 3.10+
- Node.js (if using a JS framework for frontend)
- API Key for LLM (OpenAI or similar)
### 4. Running the App
```bash
uvicorn app.main:app --reload
```
